# Vrinda Store Data Analysis | Excel Dashboard

## Project Overview
This project focuses on analyzing Vrinda Store's sales data for 2022 using Microsoft Excel. The main goal was to understand sales performance, customer purchasing behavior, and order trends through an interactive dashboard.

I worked on this project in the first week of October 2026 as part of my learning in data analysis.

## Project Objective
The objective of this project is to help Vrinda Store understand its customers, identify sales trends, and find opportunities to improve sales in the coming years.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning and Formatting

## Dataset
The dataset contains Vrinda Store's 2022 sales and order information.

- [View Dataset](https://github.com/Neelkamal-cyber/Data-Analysis/blob/main/Vrinda%20Store%20Data%20Analysis.xlsx)

## Business Questions
I used the dataset to answer the following questions:

1. How do monthly sales and order counts compare?
2. Which month had the highest sales and number of orders?
3. Which customer group purchased more, men or women?
4. What were the different order statuses in 2022?
5. Which were the top 10 states contributing to sales?
6. How do age group and gender relate to the number of orders?
7. Which sales channel generated the most sales?
8. Which product category had the highest sales?
9. What percentage of orders were successfully delivered?

## Project Process
1. **Data Cleaning:** Checked the dataset for missing values, inconsistencies, and formatting issues.
2. **Data Preparation:** Organized the data and ensured that the columns had appropriate data types and formats.
3. **Data Analysis:** Created Pivot Tables to analyze sales, orders, customer demographics, and sales channels.
4. **Dashboard Creation:** Used Pivot Charts to present the findings in a visual format.
5. **Dashboard Interaction:** Added slicers to filter the dashboard and explore the data interactively.

## Dashboard
The dashboard provides a visual summary of the store's sales performance, customer demographics, order status, and sales channels.

[View Dashboard](https://github.com/Neelkamal-cyber/Data-Analysis/blob/main/Screenshot%202026-10-25%20000955.png)

## Key Insights
Based on the analysis, I observed the following:

- Women accounted for approximately 65% of purchases.
- Maharashtra, Karnataka, and Uttar Pradesh were among the top-performing states in terms of sales.
- Customers aged 30–49 years contributed approximately 50% of sales.
- Amazon, Flipkart, and Myntra were the major sales channels.
- More than 90% of orders were successfully delivered.

## Conclusion
This project helped me understand how Microsoft Excel can be used to clean data, analyze business performance, and create interactive dashboards.

The analysis suggests that Vrinda Store could focus more on customers aged 30–49 years, particularly in the top-performing states, and use its major sales channels to improve customer engagement and sales.
